# 梦界物语 · 离线单机化（Oneiric Tales Revival）

《梦界物语》（`com.madhead.ot`，Madhead / Studio Z，2017–2018）已于 2018 年停服。
本项目研究**用原版客户端 + 本地服务端**的方式，让它重新可玩。

> ⚠️ 本项目**不包含**任何游戏客户端、APK、解包资源或美术文件。
> 仓库里只有分析文档、自写的服务端代码、从公开维基整理的结构化数据。
> 仅供技术研究与个人学习，不得用于商业用途或公开运营。

## 技术路线

原版是「瘦客户端 + 重服务端」：战斗、育成、UI 全在客户端，导灵 / 技能 / 关卡 / 存档全在服务端。
服务端已于 2018 年随域名一起消失（`oneirictales.com` 现为 NXDOMAIN）。

因此做法是：**不改客户端**，把 `api.oneirictales.com` 劫持到本机，跑一个兼容服务端。

```
Android 客户端 ──(hosts → 127.0.0.1)──► 本地服务端 ──► SQLite 存档
                     ▲
              自签证书 / 系统 CA
```

这样不会触发客户端的签名校验与反作弊检测。

## 待解决

1. **客户端能否被接管**（TLS 校验、hosts 生效）—— 未验证，是整条链路的前提
2. **加密表密钥** —— 648+ 张 TextAsset 用「!」+Base64 的块加密，密钥在 native 层
3. **关卡数据全缺** —— 包里与维基都没有，需要自造
4. **基础数值全缺** —— 维基只有技能文字描述，没有 hp/atk/spd

详见 `docs/03-mvp-plan.md` 的「风险与未决」。
